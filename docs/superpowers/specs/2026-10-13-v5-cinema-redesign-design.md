# v5 — «Кинозал за монтажным столом». Дизайн-спецификация

Ветка: `v5` (от `v4`). Автор версии: Claude (Anthropic) по запросу владельца сайта.
Другие ветки (`main`, `v2`, `v3`, `v4`) не меняются.

## 1. Цель и критерии успеха

Сайт монтажёра для блогеров. Единственное целевое действие — написать в Telegram.

Что сказал владелец:
- не нравятся «необоснованные» элементы, которые посетитель не понимает;
- нужно много иммерсивности и чтобы всё было «очень приятненько»;
- направление — между «Кинозалом» и «За монтажным столом»;
- управление — прокрутка + несколько явно подписанных мест, где можно потрогать;
- звук важен: при входе выбор «со звуком / без звука»;
- реальных роликов пока нет, но будут — нужен каркас под видео.

Критерии успеха:
1. **Правило смысла:** каждый эффект либо показывает работу монтажёра, либо ведёт к Telegram. Каждый интерактивный элемент подписан.
2. Ничего не нужно угадывать: достаточно листать вниз.
3. Ролики подключаются правкой `data.js` (путь к mp4 / постеру), без правки кода.
4. Удобно на телефоне (375px) и на десктопе; работает с клавиатуры; `prefers-reduced-motion` показывает конечные состояния без анимаций.
5. Быстрый первый экран: Three.js и звук не грузятся до момента, когда нужны.

## 2. Что убираем из v4 и почему

| Элемент | Причина |
|---|---|
| Космическая заставка («гиперпрыжок», «портал») | не связана с монтажом |
| Таймкод прокрутки в шапке | ничего не сообщает посетителю |
| Серые квадраты-слайдер под заголовком | смысл не считывается |
| Бегущая строка «Ритм · Звук · Цвет» | декорация без смысла |
| Игра «переставь клипы» и «клик выключает клип» | непонятно, зачем |
| Кастомный курсор, «луч прожектора», магнитные кнопки | мешают, а не помогают |
| 3D-лента плёнки в hero | тяжёлая и непонятная |
| Иконка из кружков у «Регулярно» | не читается |
| `montage.html` | старый прототип, не используется |

Оставляем и переосмысляем: идея «вырезать слова-паразиты» (теперь по прокрутке и с подписью), «до/после», кинозал для просмотра ролика, хлопушку (теперь — финальный «Мотор!» у кнопки Telegram), синтезированный звук.

## 3. Сюжет: сцены

Сайт — один «фильм». На десктопе справа — вертикальный **указатель сцен** (названия сцен + бегунок прогресса, клик переходит к сцене). На телефоне — тонкая полоса прогресса сверху и название текущей сцены в шапке.

**0. Вход в зал.** Полноэкранный тёмный экран: имя, одна строка «Монтаж роликов для блогеров», две кнопки: «Смотреть со звуком» / «Без звука». После выбора «гаснет свет»: затемнение уходит, на сцене появляется свечение экрана. Контент под экраном уже в DOM (SEO, без JS — виден сразу). Esc/«Без звука» — по умолчанию в фокусе первая кнопка. Выбор запоминается; при повторном визите экран показывается коротко с тем же выбором выделенным.

**1. Открытие.** Закреплённый экран. Заголовок показан «как прислали»: со словами-паразитами («ну…», «э-э», «короче»). Под ним подпись «Листайте — уберу лишнее». Прокрутка «вырезает» паразитов: каждое слово краснеет, схлопывается, текст смыкается (звук склейки). Затем появляются лид и кнопка Telegram.

**2. До / После.** Закреплённый экран 9:16 и список из 4 шагов рядом. Прокрутка проходит шаги, и кадр меняется у посетителя на глазах:
1. «Убрал паузы» — провалы на звуковой волне смыкаются;
2. «Поставил акценты» — появляются субтитры с выделенным словом;
3. «Выровнял цвет и звук» — серый кадр становится цветным, волна выравнивается;
4. «Переделал первые 3 секунды» — кадр-крючок.
В конце открывается ручной режим с подписью «Потяните, чтобы сравнить»: шторка до/после.
С реальным видео: два файла (`raw`, `fin`), синхронное воспроизведение, шторка `clip-path`.

**3. Работы — кинозал.** Горизонтальная лента «афиш» (9:16 и 16:9), движется вертикальной прокруткой. Подпись: «Нажмите на ролик, чтобы смотреть». Нажатие — ролик раскрывается на весь экран (затемнение, Esc/× закрывают, фокус возвращается). Пока нет видео — аккуратная заглушка с подписью «Ролик скоро будет здесь».

**4. Как я монтирую.** Закреплённый таймлайн с дорожками V1 / T1 / A1 (только для просмотра). Прокрутка ведёт плейхед; на трёх метках крупно появляется принцип: «Не быстрее.» / «Не громче.» / «Точнее.» с пояснением. Подпись дорожек понятными словами (Видео / Текст / Звук).

**5. Что беру и как работаем.** Спокойная сцена. Три формата с осмысленными пиктограммами (кадр 9:16, кадр 16:9, календарь). Четыре шага с линией, которая заполняется по прокрутке.

**6. Отзывы и вопросы.** Карточки отзывов (пока заглушки, помечены как временные). Вопросы — аккордеон.

**7. Финальные титры.** Короткие «титры» («Монтаж — ИМЯ»), крупный призыв «Напишите в Telegram», рядом 3D-хлопушка: хлопает при наведении/нажатии на кнопку — «Мотор!». Подвал.

## 4. Визуальный язык

- **Всегда тёмный зал.** Никаких чередований светлых/тёмных секций — это разрушает погружение. Фон — тёплый чёрный, а «свет» идёт от экрана: мягкое свечение за главным элементом сцены, его цвет меняется по смыслу (холодно-серое на «сыром», тёплое на «готовом»).
- **Палитра:** фон `#0b0a09`, поверхность `#16140f`, текст `#f2ede4`, приглушённый текст `#9b958a`, акцент «плейхед» `#ff5a36` (только для активного/важного и CTA), «паразит» — тот же акцент на зачёркивании.
- **Шрифты (с кириллицей):** заголовки — `Cormorant Garamond` (как титры в кино), текст — `Golos Text` (уже был, хорошо читается), таймкоды и подписи дорожек — `JetBrains Mono` (интерфейс монтажки).
- **Текстура:** лёгкое киноплёночное зерно поверх (очень слабое, отключается при reduced-motion).
- **Движение:** плавная инерционная прокрутка; переходы между сценами как склейки — короткое затемнение/«зажим» кадра. Длительности 300–800 мс, кривые без «прыгучих» пружин.

## 5. Звук

WebAudio, всё синтезируется (без файлов). Включается только выбором на входе или кнопкой «Звук» в шапке (иконка + подпись «Звук вкл/выкл»).
- Фон: очень тихий «тон зала» (низкий гул проектора), плавно уходит при выключении.
- Склейки: мягкий щелчок при вырезании слова и при смене сцены.
- Финал: хлопок хлопушки.
Громкость низкая, есть компрессор. При скрытии вкладки звук глушится.

## 6. Техника

- **Стек:** Vite (как было), чистый JS-модули, **GSAP + ScrollTrigger** (анимации по прокрутке), **Lenis** (плавная прокрутка), **Three.js** только для хлопушки (ленивая загрузка при подходе к финалу).
- **Структура:**
  - `index.html` — каркас, шрифты, мета;
  - `src/data.js` — весь контент (тексты, ссылки, пути к видео);
  - `src/main.js` — сборка страницы, порядок сцен, инициализация;
  - `src/lib/` — `dom.js` (утилиты), `motion.js` (Lenis + ScrollTrigger, reduced-motion), `sound.js` (звук), `nav.js` (указатель сцен), `theater.js` (полноэкранный просмотр);
  - `src/scenes/` — по файлу на сцену: `entry.js`, `opening.js`, `beforeAfter.js`, `works.js`, `editing.js`, `services.js`, `voices.js`, `finale.js`, `clapper3d.js`; каждая экспортирует `render(data) → html` и `init(root, ctx)`;
  - `src/styles/` — `base.css` (токены, типографика) и по файлу на сцену.
- **Видео-каркас:** в `data.js` у работы поля `video`, `poster`, `ratio` (`"9:16"`/`"16:9"`). Если `video` пуст — заглушка. Видео: `preload="none"`, `muted playsinline` для превью, полный звук — в кинозале.
- **Доступность:** семантические `section`/`h2`, видимый фокус, все интерактивные элементы — кнопки/ссылки с подписями, диалог кинозала с ловушкой фокуса и Esc, контраст AA, `prefers-reduced-motion` — без закреплений и анимаций, конечные состояния сразу.
- **Телефон:** те же сцены; закрепления короче; лента работ — тоже по вертикальной прокрутке; минимальный размер касания 44px.
- **Производительность:** первый экран без Three.js; шрифты `display=swap`; анимации только `transform/opacity/clip-path`.

## 7. Проверка

- Модульные тесты (Vitest) для чистой логики: разбор заголовка с паразитами, таймкоды, вычисление прогресса шагов, нормализация данных работ.
- Сборка `npm run build` без ошибок.
- Проверка в браузере: десктоп 1440 и телефон 375; reduced-motion; навигация с клавиатуры (Tab по всем элементам, Esc в кинозале); нет ошибок в консоли.
- Аудит доступности перед сдачей.

## 8. Деплой

Workflow в `v5` не трогает другие ветки. Публикация на Pages и любой `git push` — только после отдельного согласия владельца. Замечание: workflow в каждой ветке перечисляет ветки явно; если `v5` будет опубликован из своего workflow, следующий пуш в `main`/`v2`–`v4` пересоберёт сайт без `/v5/`. Решение — за владельцем, когда дойдём.

## 9. Не делаем (YAGNI)

Блог, отдельные страницы кейсов, CMS, отправка формы на сервер (форма из v4 убирается: целевое действие — Telegram, форма-прототип ничего не отправляла).
