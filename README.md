# Сайт монтажёра — ветка `v5`

> **Это версия Claude (Anthropic).** Ветка `v5` сделана ИИ-ассистентом Claude по запросу владельца сайта
> как самостоятельный редизайн. Остальные ветки (`main`, `v2`, `v3`, `v4`) в ней не менялись.

Концепция — «Кинозал за монтажным столом»: сайт как один фильм, который посетитель смотрит, просто листая страницу.
Подробности: [`docs/superpowers/specs/2026-10-13-v5-cinema-redesign-design.md`](docs/superpowers/specs/2026-10-13-v5-cinema-redesign-design.md).

## Запуск

```bash
npm install
npm run dev
```

## Где править контент

Все тексты, ссылки и пути к роликам — в `src/data.js`.
